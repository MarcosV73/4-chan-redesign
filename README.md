# 4chan Redesign

Uma releitura moderna do 4chan, mantendo a identidade nostálgica da internet dos anos 2000 com melhorias de UI/UX, responsividade e organização visual.

## Objetivo

O projeto foi desenvolvido como um redesign conceitual do site original do 4chan, buscando:

- Melhorar a experiência do usuário
- Organizar melhor o conteúdo
- Modernizar a navegação
- Tornar a interface mais agradável e acessível
- Preservar a estética underground e old web do site original

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Yarn
- Vite

## Características

- Estética Y2K / old internet
- Interface responsiva
- Sistema de boards
- Feed de posts
- Modal de login
- Navegação moderna
- Design inspirado em fóruns clássicos
- Dark mode
- Cards organizados e melhor legibilidade

## Melhorias de UI/UX

- Hierarquia visual aprimorada
- Redução de poluição visual
- Melhor escaneabilidade
- Navegação mais intuitiva
- Melhor responsividade mobile
- Botões e interações modernizadas

## Projeto

Este projeto é apenas conceitual e não possui backend funcional.
